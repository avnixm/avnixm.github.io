- I am getting the current weather using the OpenWeather API. These would include temperature, humidity, and weather conditions. The script makes a fetch request to an API endpoint
https://api.openweathermap.org/data/2.5/weather?q={city}&appid={OPENWEATHER_API_KEY}&units=metric.
It took the city from the user and used {OPENWEATHER_API_KEY} as the API key. The code fetches a JSON object that contains the information about the weather from the API. This JSON is read to find some specific details such as data.main.temp for temperature, data.main.humidity for humidity, and gets it displayed on the webpage including data.weather[0].description for conditions.

WEATHERAPI_KEY = '025e115fdfc446e29c573001241611'
- I have also used the WeatherAPI to fetch a 3-day weather forecast and check for active weather alerts. The script sends a fetch request to the API's endpoint:
https://api.weatherapi.com/v1/forecast.json?key={WEATHERAPI_KEY}&q={lat},{lon}&days=3&alerts=yes.
In the example below, {lat} and {lon} refer to the place that will be located using its latitude and longitude coordinates from the OpenWeather API, and {WEATHERAPI_KEY} is the key to the API. It will return a JSON object that contains detailed information about forecasts under data.forecast.forecastday and alerts under data.alerts.alert. I have wrapped my iterations around this data to dispense with the forecast for each day and active storms with the details on the degrees and instructions.
